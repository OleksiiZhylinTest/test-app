# Architecture Decision Records

This directory holds Architecture Decision Records (ADRs) for this repository.
ADRs are created by `solution-architect` and approved by `principal-solution-architect`.

## Format

Each ADR is a single Markdown file named `NNNN-<slug>.md` (e.g., `0001-stdlib-http-server.md`).
Use the template at `adr-template.md`. Number sequentially starting from `0001`.
