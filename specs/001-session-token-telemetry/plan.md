# Implementation Plan: Agentic SDLC Token Consumption Telemetry

**Branch**: `001-session-token-telemetry` | **Date**: 2026-06-05 | **Spec**: [spec.md](spec.md)

## Summary

Automatically generate a human-readable Markdown report of token consumption per API call after each Claude Code agentic session. The Stop hook pipes the session transcript JSONL path (provided by Claude Code) to a Python script that parses turns and steps, then writes `generated/debug/claude_session_<id>.md` with session totals, per-turn per-step tables, and a Hotspots section ranking the top 5 cache-write steps.

## Technical Context

**Language/Version**: Python 3.x (stdlib only)

**Primary Dependencies**: `json`, `pathlib`, `argparse`, `datetime`, `collections` (all stdlib — no third-party packages)

**Storage**: Files — reads session JSONL transcript (provided by Claude Code); writes Markdown report to `generated/debug/`

**Testing**: pytest (project standard); quickstart validation scenarios cover the primary flows

**Target Platform**: Local developer machine (Windows/Linux/Mac — wherever Claude Code runs)

**Project Type**: CLI tool + framework hook (not part of the Jira Sprint Reporter product; framework-level tooling)

**Performance Goals**: Report generation completes in <5 seconds for any typical session (SC-001)

**Constraints**: Zero external dependencies; hook must not block session completion; stderr suppressed in hook context

**Scale/Scope**: Single-user local tool; sessions of typically 10–200 turns; report file ~10–100 KB
